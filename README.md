# QR 코드 생성기

이 프로젝트는 간편하게 QR 코드를 생성하고 이미지를 다운로드할 수 있는 웹 애플리케이션입니다.

## 사이트 주소

[https://crazythink.github.io/qr](https://crazythink.github.io/qr)

## 주요 기능

- 텍스트 입력을 통한 QR 코드 생성
- 색상 선택 및 점 스타일(네모/원) 선택
- 실시간 미리보기 및 PNG 이미지 다운로드

## 기술 스택

- Vue 3
- TypeScript
- Vite
- Element Plus
- qrcode (QR 코드 생성 라이브러리)

## 사용 방법

1. 사이트에 접속합니다: [https://crazythink.github.io/qr](https://crazythink.github.io/qr)
2. QR 코드에 넣을 내용을 입력합니다.
3. 색상과 점 스타일을 선택합니다.
4. 미리보기 하단의 "다운로드" 버튼을 눌러 이미지를 저장합니다.
